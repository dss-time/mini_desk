# MiniDesk v1.0.1

## 修复

- 修复外观滑块拖动时反复重建分组布局导致的图标闪动；现在直接更新画刷和裁剪，圆角的原生窗口区域在拖动结束时应用。
- 修复圆角预览不能实时跟随滑块的问题。
- “语言与区域”新增可操作的“应用语言”下拉框，与顶部语言选项双向同步，切换后立即更新界面并保存设置。
- 明确区分“应用语言”和“区域格式”；区域格式独立控制日期和数字格式。

## 下载与更新

- 普通 Intel / AMD Windows 电脑选择 x64；Windows ARM 设备选择 ARM64。
- 安装版：运行对应的 `MiniDesk-Setup-x64.exe` 或 `MiniDesk-Setup-arm64.exe`。
- 便携版：下载对应的 ZIP，完整解压后运行 `MiniDesk.exe`，不要单独复制 EXE。
- 更新前，从系统托盘右键菜单选择“退出”。旧版仍在后台运行时，新版启动请求会转交给旧版。
- 使用新目录时，请更新桌面快捷方式；已开启开机启动的便携版用户，请在新版中关闭后重新开启开机启动，以更新启动路径。
- 保留 `%LOCALAPPDATA%\MiniDesk` 中的配置和布局数据。

## 验证

- Windows x64：16 项自检通过，包括语言选项双向同步、实际导航文案刷新、区域格式独立性，以及外观预览回归检查。
- 提供 .NET 10 自包含 x64 / ARM64 构建，无需另装运行时。
- ARM64 未进行原生设备运行验证；自动化自检不等同于人工目视确认滑动全程无闪动。
