# MiniDesk v1.0.6

## 简体中文

- 优化桌面常驻绘制预算：后台桌面采用软件绘制以减少图形开销；管理窗口和对话框可见时恢复系统默认加速，全部交互窗口最小化、隐藏或关闭后回收临时缓存。
- 停用分组不再创建并保留隐藏窗口；关闭分组窗口时解除模型集合事件订阅，避免已关闭窗口被模型引用。重新启用分组保留原有内容和布局。
- 外观页加入平滑滚轮过渡，支持连续滚动、反向和中断；动画结束及页面卸载时释放临时位图缓存，尊重系统减少动画和高对比度设置。
- 新拟物阴影改为复用小尺寸纹理和可伸缩边缘，阴影缓存限制为 2 MiB；保留凸起、凹陷、圆角及明暗主题。
- 上传图标按最长边 128 像素缩略解码，预览缓存限制为 48 项；普通文件图标缓存限制为 256 项，内置分组图标独立保留。
- 提供 .NET 10 自包含 x64 / ARM64 便携包与安装包。

### 验证与范围

Windows x64 执行 32 项应用自检及安装包检查，覆盖绘制预算切换、多窗口与最小化、停用分组、关闭事件引用、平滑滚动、图标缓存，以及快照、整理、撤销和原有文件保护流程。

同机 5 分组独立对照测试中，首次后台常驻专用内存约从 151 MiB 降到 75–90 MiB，打开管理窗口约为 233–236 MiB，打开后再关闭约为 204–210 MiB。数值取决于设备、图形驱动、内容及使用历史，不是固定内存上限；WPF 渲染事件测量也不等同于实际显示延迟。ARM64 为交叉构建，未在原生 ARM64 设备运行验证。

更新前退出 MiniDesk，替换便携版文件或运行对应架构安装器。保留 `%LOCALAPPDATA%\MiniDesk` 以继续使用分组、项目和快照；不要混用架构。回退时使用旧版程序及升级前的数据备份。

## English

- Reduced desktop residency overhead with software rendering while only desktop groups are active. Visible managers and dialogs use the system's default acceleration; temporary caches are reclaimed when interactive windows are minimized, hidden or closed.
- Disabled groups no longer retain hidden windows. Closed group windows unsubscribe from model collection events; re-enabling preserves their data and layout.
- Smooth appearance-page wheel scrolling supports reversal and interruption, releases temporary caches, and respects reduced animation and high contrast settings.
- Reusable shadow textures with a 2 MiB cache budget. Uploaded icons decode to thumbnails of at most 128 pixels on the longest side, with 48 preview entries and 256 ordinary file icon entries; built-in group icons remain available.
- Self-contained .NET 10 x64 / ARM64 portable packages and installers.

Validation: 32 application self-tests and installer checks on Windows x64. Measured memory depends on hardware, drivers, content and usage history and is not a guaranteed ceiling. ARM64 is cross-built and has not been tested on native ARM64 hardware.

Exit MiniDesk before upgrading. Preserve `%LOCALAPPDATA%\MiniDesk` and do not mix architectures. Roll back using the previous application and a pre-upgrade data backup.
