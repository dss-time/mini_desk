# MiniDesk v1.0.5

## 简体中文

- 修复桌面分组标题栏独立的不透明底色，去除多余浅色矩形，使标题栏空白区域与面板使用一致的透明度；保留拖动、圆角及标题控件交互。
- 管理窗口左上角改用正式的蓝色 MiniDesk 应用图标，与程序图标一致。
- 在已有桌面窗口回归检查中增加实际渲染像素验证，覆盖 0% 和 50% 透明度下标题栏与面板的一致性。
- 提供 .NET 10 自包含 x64 / ARM64 便携包和安装包。

验证：Windows x64 执行 27 项应用自检及安装包检查。ARM64 为交叉构建，未在原生 ARM64 设备运行验证。

更新前退出 MiniDesk，替换便携版文件或运行对应架构安装器。保留 `%LOCALAPPDATA%\MiniDesk` 以继续使用原有分组、项目和快照；不要混用架构。回退时使用旧版程序及升级前的数据备份。

## English

- Removed the opaque rectangular fill behind desktop group headers. Empty header areas now share the panel's opacity while dragging, rounded corners and controls remain available.
- The manager's top-left branding now uses the official blue MiniDesk application icon.
- Extended the existing desktop window regression check with rendered pixel alpha comparisons at 0% and 50% panel opacity.
- Self-contained .NET 10 x64 / ARM64 portable packages and installers.

Validation: 27 application self-tests and installer checks on Windows x64. ARM64 is cross-built and has not been verified on native ARM64 hardware.

Exit MiniDesk before upgrading. Preserve `%LOCALAPPDATA%\MiniDesk` and do not mix architectures. Roll back using the previous application and a pre-upgrade data backup.
