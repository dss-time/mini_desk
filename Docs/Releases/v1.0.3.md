# MiniDesk v1.0.3

## 简体中文

- 新增“整理桌面”：首页或分组管理进入，先预览每个项目的目标分组，再确认应用；取消不改变桌面。
- 仅建议整理未分组、可见的桌面文件及已知快捷方式。未知项目、文件夹默认留在桌面；已有 Word / Excel / PPT / PDF 专用组优先，否则归入办公。保留现有分组布局，只按需创建非空分类。
- 整理前自动创建快照，持久化本次整理记录，支持“撤销上次整理”。撤销只处理未被手动移动的项目；恢复失败保留记录以供重试，新创建的空分组不会自动删除。
- 重构图标右键菜单：打开、移动到分组、新建分组并移入、移回桌面、打开所在位置、Windows 属性。当前分组显示勾选，未启用分组不能移入；无空余位置时提示先扩大分组。
- 重构分组右键菜单：展开/收起、收起样式、重命名、更换图标、锁定位置、删除分组。锁定禁止拖动与缩放，不影响文件操作或展开/收起。
- 菜单复用 Fluent 样式及中英文资源，危险操作使用红色；恢复失败不会直接删除图标归属。
- 提供 .NET 10 自包含 x64 / ARM64 便携包与安装包，无需另装 Runtime。

升级前请在托盘右键选择“退出”，再替换便携版文件或运行对应架构安装器。保留 `%LOCALAPPDATA%\MiniDesk` 即可继续使用已有布局。建议先备份该目录；不要混用两种架构的文件。若需回退，请先退出并备份当前配置，再使用上版程序及升级前的数据备份；不要覆盖或删除桌面真实文件。

### 验证与当前范围

- Windows x64：23 组应用自检；x64 和 ARM64 发布构建及安装包检查。
- ARM64 为交叉构建，尚未在原生 ARM64 设备上执行验证。
- 此阶段不启用后台自动整理、不提供个人分类偏好记忆；Windows Shell 与托盘菜单仍沿用原有功能。
- 普通文档路径不变；快捷方式沿用受控收纳与安全恢复机制。没有网络、广告或遥测功能。

## English

- **Organize desktop**: preview each ungrouped item's destination before applying. Cancel changes nothing. Unknown items and folders stay on the desktop; existing dedicated Office groups take priority. Existing layouts are preserved.
- A snapshot and a persistent batch record protect organization. **Undo last organization** restores unchanged items only. Failed restoration keeps records for retry; newly created empty groups remain.
- Item context menus now provide Open, Move to group, Create group and move, Return to desktop, Open containing folder and Windows Properties.
- Group context menus provide Expand/Collapse, Collapsed style, Rename, Change icon, Lock position and Delete group. Locked groups cannot be dragged or resized, but their items remain usable.
- Shared Fluent menus, Chinese/English labels, checked current groups and clearly marked destructive actions. Disabled or full destinations are protected.
- Self-contained .NET 10 x64 / ARM64 portable packages and installers.

Exit MiniDesk from its tray menu before upgrading. Keep and back up `%LOCALAPPDATA%\MiniDesk` to preserve layouts. Do not mix architectures. To roll back, exit first and restore the previous application together with a pre-upgrade configuration backup; never delete real desktop files.

23 Windows x64 application self-tests cover the shipped features. ARM64 is cross-built and has not been tested on native ARM64 hardware. Background organization and personal preference memory are not enabled in this phase. Windows Shell and tray integrations retain their existing behavior.
