# MiniDesk v1.0.4

## 简体中文

- 统一管理窗口、按钮、表单、分组图标和收起样式的新拟物外观，并保留键盘焦点提示及系统减少动画设置。
- 重新设计管理窗口的“新建分组”：使用紧凑、提前创建并复用的窗口内面板；打开时保留后台页面，图标提前加载，过渡期间缓存静态内容以减少重复绘制。支持名称校验、系统图标、自定义上传、默认状态和创建后是否显示。
- 系统分组图标使用 Windows Shell 图标及本机文件关联，兼容已有分组和自定义图标。
- 创建快照提供空状态、执行状态、成功和失败反馈；整理桌面与撤销操作提供进度、结果及无可撤销记录的说明。
- `--preview` 使用独立的示例桌面和本地服务，可体验快照、整理、撤销与恢复，不操作真实桌面。
- 提供 .NET 10 自包含 x64 / ARM64 便携包和安装包。

升级前退出 MiniDesk，替换应用文件或运行对应架构安装器；保留 `%LOCALAPPDATA%\MiniDesk` 以继续使用现有布局。不要混用两种架构的文件。回退时使用旧版程序及升级前的数据备份，勿删除桌面真实文件。

### 验证范围

Windows x64 执行 27 项应用自检，覆盖面板复用、快速重开、输入校验、创建与取消，以及快照、整理、撤销和已有桌面文件保护流程。动画指标为 WPF 渲染事件测量，不代表所有设备的显示延迟。ARM64 为交叉构建，未在原生 ARM64 设备执行验证。

## English

- Unified soft, neumorphic controls and Windows system group icons, with keyboard focus cues and respect for reduced animation settings.
- Redesigned the manager's Create group flow as a compact, pre-created, reusable in-window panel. The background remains visible; icons preload and static content is cached during transitions.
- Snapshot, organization and undo actions now expose progress, outcomes, empty states and failures.
- `--preview` uses an isolated sample desktop with functional local snapshot, organize, undo and restore services.
- Self-contained .NET 10 x64 / ARM64 portable packages and installers.

Exit MiniDesk before upgrading. Preserve `%LOCALAPPDATA%\MiniDesk` and do not mix architectures. Roll back using the previous binaries and a pre-upgrade data backup.

Validation: 27 application self-tests on Windows x64. Rendering timings are measured from WPF rendering events. ARM64 is cross-built and has not been verified on native ARM64 hardware.
