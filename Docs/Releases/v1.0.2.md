# MiniDesk v1.0.2

## 简体中文

- 新建分组新增六种系统图标：财经、代理工具、Excel、PPT、PDF、Word；共 18 种内置图标。
- 图标列表支持滚动，新增图标可即时预览并保存；补齐中英文名称。
- 修复公共桌面快捷方式因写入权限不足而无法移出分组的问题：优先还原原位置，必要时还原到个人桌面；同名文件不会被覆盖，失败时保留分组记录。
- 包含实时外观更新、圆角/不透明度拖动闪烁及语言切换修复。
- 提供 .NET 10 自包含的 x64 / ARM64 便携包及安装包，无需额外安装 Runtime。

升级：完全退出旧版（托盘右键 → 退出），将便携包解压到独立目录，或运行对应架构安装包。保留 `%LOCALAPPDATA%\MiniDesk` 即可继续使用已有布局。不要混合两种架构的文件。

## English

- Six new built-in group icons: Finance, Proxy tools, Excel, PPT, PDF and Word (18 total).
- Scrollable icon picker with immediate preview, persistence and Chinese/English labels.
- Restore public-desktop shortcuts to the personal desktop when public-desktop write access is denied. Existing files are never overwritten; failed restoration keeps the group entry.
- Includes live appearance updates and language-selector fixes.
- Self-contained .NET 10 x64 / ARM64 portable packages and installers.

To upgrade, exit MiniDesk from its tray menu before replacing application files or running the matching installer. Keep `%LOCALAPPDATA%\MiniDesk` to retain layouts. Do not mix architectures.

ARM64 packages are cross-built; native ARM64 execution is not verified on this x64 test machine.
