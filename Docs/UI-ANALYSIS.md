# UI 图分析

## 视觉层级

参考图由两个层级组成：桌面上的五个分类浮层，以及独立的 MiniDesk 管理中心。桌面浮层是主体验，管理中心只承担配置和批量管理。

分类浮层采用冷白半透明背景、约 16px 圆角、1px 高光边框和紧凑标题栏。标题栏从左到右为分类色块图标、名称、数量角标和收起按钮。展开态内部使用自由坐标布局；收起态提供横向胶囊、竖向图标、仅图标三种密度。

管理中心延续 Windows 11 Fluent 习惯：浅蓝灰侧栏、白色内容卡片、蓝色主操作、Segoe UI Variable/Segoe Fluent Icons。性能优先，因此不加入持续阴影动画、粒子、模糊动画或后台刷新。

## 尺寸映射

- 分类区域：默认 380×250 DIP，最小 260×170 DIP
- 圆角：默认 16 DIP，可调 8–28
- 标题栏：默认 42 DIP，可调 34–56
- 内部图标单元：82×86 DIP，自由坐标保存
- 横向胶囊：220×62 DIP
- 竖向图标：94×126 DIP
- 仅图标：64×64 DIP
- 管理中心：980×640 DIP，左侧导航 185 DIP

## 交互映射

- 拖动标题栏：移动分类区域并在释放时保存
- 拖动右下角：缩放并在释放时保存
- 文件拖入：读取 `CF_HDROP` 路径，创建关联记录
- 内部图标拖动：更新该项目的 X/Y 坐标
- 双击内部图标：交给 Windows Shell 打开
- 单击收起卡片：恢复展开态
- 右键分类：展开、三种收起样式、重命名、设置、删除
